# ZCHAT AI + Messaging Fix Plan

_38 findings across 9 research areas. Generated from Fable research fan-out._

**Legend:** ⚑ = needs a decision before fixing · 💵 = money/security · effort S/M/L

## Key facts
- **Model catalog refresh:** backend caches Venice models **24h in-memory** (resets on restart); admin flush endpoint exists. New models/prices propagate within a day.
- **AI top-up ZEC lands at:** `u18p29tusy2xtngwhea…ngufyt30` (ZCHAT_AI_TOPUP_ZADDR on moltbot); credited via ai-topup-watcher.
- **Pricing source:** hand-seeded `AiModelPricing` DB row is authoritative, else live Venice price × markup. `isFreeTier` only settable via DB row.
- **Trial gating:** hard-coded 5-model whitelist `FREE_TIER_MODELS`; trial = grant active & no credited deposit; $0.20 once per wallet.
- **Model grouping:** client-side by id-prefix heuristic (`PROVIDER_PREFIXES`); singleton providers render inline instead of folding into Others.
